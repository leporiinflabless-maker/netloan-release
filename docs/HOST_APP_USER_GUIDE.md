# 穿云引线 · Host app 使用说明

> 适用应用：**穿云引线 · 我要出口**（Host 端，包名 `com.netloan.host`）
> 作用：把一台远端设备（Client 端，插着 SIM 卡）的网络出口"借"到本机使用——本机上网时对外显示的就是远端 Client 的公网 IP。

---

## 1. 这个 app 是做什么的

- **Client 端**（对方设备）：插 SIM 卡、建房间，作为"远程出口来源"。
- **Host 端**（本 app，你的设备）：加入房间后，把远端出口拿来用。有两种用法：
  - **VPN 自用**（默认，任何设备可用，含非 Root）：只让**本机**流量走远端 IP。
  - **热点共享**（仅 Root 设备）：开热点，让连上来的**其他设备**也走远端 IP。

一句话：Client 提供 IP，Host 借用 IP。

---

## 2. 首次使用流程

### 2.1 加入房间
1. 打开 app，首页顶部会显示「未加入任何穿云引线房间」。
2. 从 Client 端拿到 **6 位房间码** + **4 位密码**（或让对方生成二维码）。
3. 首页点：
   - **扫码加入**：对准 Client 端生成的二维码即可；或
   - **手动输入房间码**：输入 6 位数字房间码 + 4 位密码（大写字母 + 数字），点「验证并加入」。
4. 加入成功后，首页 Hero 变为「穿云引线中」，并出现房间信息卡（房间码 / 剩余时间 / 已用量 / 出网状态）。

### 2.2 选择出口方式

打开右上角 **设置**，在「远程出口方式」区：

- **VPN 自用（仅本机）**：打开开关 → 系统弹「VPN 连接请求」→ 允许。之后本机所有流量经远端 IP 出网。
  - 非 Root 设备也能用，这是默认推荐方式。
  - 状态显示「已开启 · 本机走远程 IP」即成功。
  - 需先加入房间，未加入会提示「请先加入房间后再开启」。
- **热点共享（仅 Root）**：进入「控制台」点「启用穿云引线（打开热点）」，其它手机/电脑连上这个热点后即走远端 IP。

---

## 3. 控制台（会话页）

首页点「进入穿云引线控制台」进入。这里能看到：

| 区块 | 说明 |
|------|------|
| 状态 Hero | 待启用 / 穿云引线中 / 已暂停 |
| 剩余时间 | 房间到期倒计时 |
| **出网状态** | **出网正常** / **出网异常（重拨中）**，见第 5 节 |
| 用量 | 累计用量（纯时长模型，无流量上限） |
| 热点卡 | SSID / 密码 / 已连接设备数，可一键复制（Root 热点模式） |
| 实时速率 | 上行 / 下行 + 60 秒曲线 |
| 启用/关闭穿云引线 | 开关热点（Root 热点模式） |
| 释放 | 释放房间 |

**暂停/恢复**：Root 热点模式下可从通知栏暂停穿云引线（关热点，房间保留），需要时再恢复。

## 4. 保活设置（重要，务必开启）

Host 需长期在线，否则被系统省电策略杀掉会导致穿云引线中断。设置页「保活设置」逐项开启：

- **电池优化白名单**：点一下即可。
  - Root 设备会**自动加入**并显示「已加入」（app 直接写入系统 doze 白名单）。
  - 非 Root 设备点击后在系统弹窗里选「允许」。
  - 注意：MIUI 的「省电策略·无限制」和这里的「电池优化白名单」是**两套机制**，两个都建议开。
- **自启动 / 后台运行**：点击跳转 MIUI 本应用权限页，打开「自启动」。
- **精确闹钟**：允许系统每 75s 唤醒保活服务（Android 12+ 需单独授权）。
- **防睡眠 · 保持在线**：灭屏时保持后台运行（耗电会增加，长时间借出建议开）。

---

## 5. "出网正常 / 出网异常（重拨中）"怎么理解

- **出网正常**：Host → 远端 Client → SIM 出网整条链路通畅，可正常上网。
- **出网异常（重拨中）**：链路暂时不通，系统正在自动重拨。常见原因与处理：
  1. **Client 端离线或信号差**：让对方检查设备在线、SIM 有网。
  2. **刚加入/刚重启，链路预热中**：等待 10~60 秒通常自动恢复。
  3. **（Root）本机出口组件被系统清理**：新版本已内置自愈——检测到异常会在一个健康周期内（约 30 秒）自动重拉，无需手动干预。若长时间不恢复，重启一次设备即可（开机自启会重建整条链路）。

---

## 6. Root 设备额外说明

- 首次安装后若检测到 Root，app 会自动安装系统模块（开机自启 / 看门狗 / 热点出口基座），并提示**重启生效**。选「立即重启」最省事。
- 系统模块负责：开机自动拉起出口组件、看门狗保活、热点出口基座。
- 因此 Root 设备遇到疑难问题时，**重启一次**往往能恢复到干净可用状态。

## 7. 常见问题（FAQ）

**Q：非 Root 手机能用吗？**
能。用「VPN 自用」，只让本机走远端 IP。热点共享才需要 Root。

**Q：VPN 开关打不开 / 提示需要房间？**
先加入房间（6 位房间码 + 4 位密码），再回设置页开 VPN。

**Q：电池白名单已在 MIUI 设了"无限制"，app 还显示"未加入"？**
MIUI 省电策略 ≠ 系统电池优化白名单。在 app 设置页点一下「电池优化白名单」，Root 设备会自动补加并显示「已加入」。

**Q：一直显示"重拨中"？**
见第 5 节。多数是 Client 端离线或链路预热；Root 设备已内置自愈，长时间不恢复就重启设备。

**Q：房间被释放/到期了？**
会自动回到首页并提示。重新加入新房间即可。

**Q：出网慢？**
远端出口经隧道 + 远端 SIM 上行，速度受远端网络与信号制约，属正常上限。

## 8. 名词速查

| 名词 | 含义 |
|------|------|
| 房间 | 一次 Client↔Host 的配对，用 6 位房间码 + 4 位密码标识 |
| 出口来源 | 提供远程 IP 的 Client 端设备 |
| VPN 自用 | 只让本机走远程 IP 的模式（默认，非 Root 可用） |
| 热点共享 | Root 下开热点，让其它设备也走远程 IP |
| 出网状态 | 当前链路是否通（正常 / 重拨中） |
