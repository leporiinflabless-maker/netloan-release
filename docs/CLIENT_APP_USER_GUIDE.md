# 穿云引线 · Client app 使用说明

> 适用应用：**穿云引线 · 我是出口**（Client 端，包名 `com.netloan.client`）
> 作用：把本机（插着 SIM 卡的设备）的网络出口"借"给远端的 Host 设备使用——Host 上网时对外显示的公网 IP，就是本机的 IP。

---

## 1. 这个 app 是做什么的

- **Client 端**（本 app，你的设备）：作为"远程出口来源"。建一个房间，把出口借给对方。
- **Host 端**（对方设备）：加入你的房间后，把你的 IP 拿去用。

一句话：**你提供 IP，对方借用**。可以自用（自己的另一台设备当 Host）。

> 建议：Client 端设备要**长期在线、SIM 有网、电量充足**（可插电常供），否则对方会断网。

---

## 2. 快速上手（建房 → 借出）

### 2.1 创建房间
1. 打开 app，首页状态位显示"未开始"。
2. 点主按钮 **创建穿云引线房间**（无需填表，直接建）。
3. 建好后进入等待页，显示：
   - **6 位房间码**（如 `388-884`）
   - **4 位密码**（大写字母 + 数字）
   - 有效至 / 已用量
   - 状态横幅："等待接入"
4. 把房间码 + 密码给对方，或点 **分享** 发送加入链接 / **复制** 复制房间码+密码。

### 2.2 对方接入
- 对方（Host）用房间码+密码或扫码加入。
- Host 接入后，本机自动进入 **房间活跃页**，状态变为"已连接"。

---

## 3. 房间活跃页

对方接入后进入，能看到：

| 区块 | 说明 |
|------|------|
| 状态 Hero | 已连接 / 出口异常(重连处理中) / 等待重连 |
| 房间码 / 密码 | 可点击复制 |
| 连接方式 | 中继 / P2P |
| 有效至 | 到期倒计时 |
| **出口健康** | 正常 / 异常（见第 5 节） |
| 实时速率 | 上下行速率 + 波形（本机计量文件差分，观察用） |
| 用量 | 累计用量 + 剩余时间 |
| 修改房间密码 | 仅房主可改，自动生成合规 4 位密码，可"换一个" |
| 释放 | 释放房间（对方立即断开） |

> **修改密码**：仅建房的这台设备（房主）能改；升级前建的老房间可能没有房主令牌，会提示无法改，重新建房即可。

## 4. 保活设置（重要，务必开启）

Client 需长期在线，否则被系统省电策略杀掉会导致对方断网。设置页（右上角 ⚙）里：

**保活体检**（可观测 + 一键修复）：
- 精确闹钟心跳、进程运行时长、重启次数、常驻服务、JobScheduler、场景保活的状态一目了然。
- 点 **立即体检** 会检查并按需重启保活组件。各行也可点击单独修复。

**保活设置**（逐项开启）：
- **电池优化白名单**：点击后在系统弹窗选"允许"。
  - 注意：MIUI 的"省电策略·无限制"与这里的"电池优化白名单"是**两套机制**，两个都建议开。
- **自启动 / 后台运行**：跳转 MIUI 自启动管理，打开本应用。
- **精确闹钟**：Android 12+ 需单独授权，允许定时唤醒保活。

**高级**：
- **防睡眠 · 保持在线**：默认开启，灭屏时保持后台运行避免掉线（耗电增加，可关）。

**通知**：建议开启通知权限，便于查看在线/连接等状态。

**数据**：
- **清除本机记录**：清空本地房间信息与用量文件（不影响服务端）。

## 5. "出口健康：正常 / 异常"怎么理解

- **正常**：本机 → 对方 Host 的链路通畅，出口可用。
- **异常（重连处理中 / 等待重连）**：链路暂时不通，系统正在自动重连。常见原因与处理：
  1. **本机 SIM 没网 / 信号差**：检查移动数据是否开启、信号是否正常。
  2. **本机被系统省电杀后台**：按第 4 节把保活项全开。
  3. **对方 Host 未接入或已离线**：等对方上线；对方接入后自动恢复"已连接"。
  4. **刚建房/刚重启，链路预热中**：等待 10~60 秒通常自动恢复。

## 6. 常见问题（FAQ）

**Q：需要 Root 吗？**
不需要。Client 端普通设备即可，插 SIM、保持在线就行。

**Q：提示"只能 20 分钟建一次" / 建房入口点不动？**
多为上一个房间残留占用。到期/已关闭的房间 app 会自动清理并恢复建房入口；若仍异常，进设置"清除本机记录"后重建。

**Q：出口一直"异常/重连中"？**
见第 5 节。多数是本机 SIM 没网、被省电杀后台，或对方未上线。

**Q：房间被释放/到期？**
会自动回到首页并提示，重新建房即可。

**Q：出口慢？**
速度受本机 SIM 上行带宽与信号制约，属正常上限。

## 7. 名词速查

| 名词 | 含义 |
|------|------|
| 房间 | 一次 Client↔Host 的配对，用 6 位房间码 + 4 位密码标识 |
| 房主 | 建房的这台 Client，可改房间密码 / 释放房间 |
| 出口来源 | 提供远程 IP 的设备，即本机 |
| 连接方式 | 中继（经服务器转发）/ P2P（点对点） |
| 出口健康 | 当前链路是否通（正常 / 异常重连中） |
